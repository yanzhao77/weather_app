## 一、项目概述

### 1.1 产品定位

**NEXUS WEATHER** 是一款面向未来感与硬核科技风格的天气应用。它不只是一个"查天气"的工具，更是一个**交互式气象数据终端**——以科幻电影中 HUD（平视显示器）、军事级数据面板、赛博朋克信息流为视觉灵感，将枯燥的天气数据转化为沉浸式的数字体验。

### 1.2 核心目标

| 目标 | 描述 |
|------|------|
| 视觉冲击 | 大胆采用暗色基底 + 霓虹渐变 + 发光描边 + 故障艺术动效 |
| 数据密度 | 一屏展示温度、体感、湿度、风速、气压、紫外线、日出日落等完整指标 |
| 动效驱动 | 粒子系统、扫描线、波形动效、数据刷新闪烁 |
| 响应式 | 适配手机与平板，横竖屏皆可 |
| 离线可用 | 缓存最近一次天气数据，无网络时展示历史快照 |

### 1.3 目标用户画像

- 科技爱好者 / 数码极客
- 赛博朋克 / 未来主义美学受众
- 对数据可视化有审美的天气预报常用用户
- Flutter 开发者（作为开源参考项目）

## 二、技术栈选型

| 层 | 技术 | 说明 |
|----|------|------|
| 框架 | **Flutter 3.x** (Dart 3.x) | 跨平台 UI 框架 |
| 语言 | Dart 3 | 健全空安全、Records、Patterns |
| 状态管理 | **Riverpod 2.x** | 编译安全、依赖注入、自动 dispose |
| 网络层 | **Dio** + Retrofit 风格封装 | 拦截器、重试、日志 |
| 数据源 | **OpenWeatherMap OneCall API 3.0** | 当前天气 + 7 天预报 + 分钟级预报 |
| 本地缓存 | **Hive** / **Isar** | 极速 NoSQL 本地存储 |
| 定位 | **Geolocator** + **Geocoding** | 自动获取当前位置 |
| 动画引擎 | **Flutter built-in Animation** + **Lottie** + **Rive**（可选） | 粒子、波形、HUD 动效 |
| 图表 | **FL Chart** / **Syncfusion** | 温度曲线、风速玫瑰图 |
| 字体 | **Orbitron**（数字）+ **JetBrains Mono**（代码风格） | 科技感字体 |
| 图标 | **Custom painted icons** + Lucide 风格 | 自绘发光图标 |
| 构建 | **flutter_native_splash** + **launch_icons** | 启动屏和图标 |

## 五、数据流设计

### 5.1 API 集成

**主数据源**: OpenWeatherMap One Call API 3.0

```http
GET https://api.openweathermap.org/data/3.0/onecall
  ?lat={lat}&lon={lon}
  &exclude=minutely
  &units=metric
  &appid={API_KEY}
```

**响应结构**:
```json
{
  "current": { "temp", "feels_like", "humidity", "wind_speed", "uvi", ... },
  "hourly": [ { "dt", "temp", "weather", ... } × 48 ],
  "daily": [ { "dt", "temp.max", "temp.min", "weather", ... } × 7 ]
}
```

**备用数据源**（fallback）:
- WeatherAPI.com（免费层）
- 和风天气 API（中文优先，适配国内用户）

### 5.2 数据流顺序

```
1. App 启动 → ProviderScope 初始化
2. HomeProvider 自动触发 → 获取 GPS 定位
3. 定位成功 → 调用 WeatherRepository.getCurrentWeather(lat, lng)
   3a. Repository 先检查 Hive 缓存 → 有则返回快照
   3b. 同时发起远程 API 请求
   3c. API 成功 → 更新 Hive 缓存 → Riverpod state 更新 → UI 重建
   3d. API 失败 → 保留缓存数据 → UI 展示"离线模式"指示
4. 定位失败 → 展示默认城市（北京）或提示用户手动搜索
5. 用户搜索城市 → Geocoding → 重复步骤 3
```

### 5.3 缓存策略

| 数据 | 缓存时间 | 存储方式 |
|------|---------|---------|
| 当前天气 | 30 分钟 | Hive Box |
| 逐小时预报 | 30 分钟 | Hive Box |
| 7 天预报 | 1 小时 | Hive Box |
| 城市列表 | 7 天 | Hive Box |
| 用户设置 | 永久 | SharedPreferences |

## 八、动效与交互设计

### 8.1 持续动效

| 动效 | 实现方式 | 描述 |
|------|---------|------|
| 粒子背景 | CustomPainter + AnimationController | 浮动数据点，缓慢漂移 |
| CRT 扫描线 | Stack + IgnorePointer | 半透明水平线持续滚动 |
| 网格地面 | CustomPainter | 透视网格，科技感 HUD 基底 |
| 数字呼吸 | 周期性 Opacity 动画 | 温度数值轻微的"脉搏"效果 |

### 8.2 触发式动效

| 动效 | 触发条件 |
|------|---------|
| 故障闪烁 (Glitch) | 页面加载 / 数据刷新 |
| 数据刷新扫描 | 下拉刷新时，扫光效果扫过屏幕 |
| 数字滚动 (Flip) | 温度数值变化时 |
| 卡片浮入 | 页面进入时，卡片按延迟依次弹出 |
| 脉冲波纹 | 点击地点标记时 |

### 8.3 交互反馈

- 点击 Haptic Feedback（震动反馈）
- 长按显示更详细的气象数据
- 滑动切换时间轴（小时预报可左右滑动）
- 捏合缩放查看不同粒度预报
